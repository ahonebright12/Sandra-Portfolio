# Sandra's Personal Portfolio

A personal portfolio website built with plain HTML, CSS, and JavaScript. The code is deliberately split into separate files so each part has one clear job.

## Project files

- `index.html` — the page structure and text that visitors read.
- `style.css` — colours, spacing, layout, typography, animations, and mobile responsiveness.
- `script.js` — the mobile navigation menu and automatic footer year.
- `sandra-portrait.png` — the profile photo shown on the page.
- `Sandra-CV.pdf` — the CV linked from the page.

## Open the website in VS Code

1. Extract the ZIP file into a folder you can find easily.
2. Open VS Code.
3. Select **File → Open Folder** and choose the extracted portfolio folder.
4. Open `index.html` to read or edit the HTML.
5. To view the website, open `index.html` in a browser. If you have the **Live Server** extension, right-click the file and select **Open with Live Server**.

## How the code is organised

1. Start with `index.html` to change headings, paragraphs, links, and project descriptions.
2. Open `style.css` to change how the website looks. CSS rules are spaced out and grouped so they are easier to follow.
3. Open `script.js` for the small interactive features. You do not need JavaScript to edit the text or colours.
